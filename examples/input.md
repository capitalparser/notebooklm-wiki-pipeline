# Example Input

Claude Code 세션에서 `/pdf-to-wiki`를 호출할 때의 입력 예시입니다.

```text
/pdf-to-wiki https://drive.google.com/file/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/view K-IFRS 1109 금융상품 --topic audit-accounting
```

파일 ID만 넘길 수도 있습니다.

```text
/pdf-to-wiki 1AbCdEfGhIjKlMnOpQrStUvWxYz K-IFRS 1109 금융상품 --topic audit-accounting
```

이 예시는 형식 설명용 더미 ID입니다. 실제 실행 시에는 접근 권한이 있는 Google Drive PDF URL 또는 file ID를 사용하세요.
